# College Student Assistant Chatbot

A full-stack web application built using Python Flask and SQLite.

## Features

- Student Registration
- Student Login
- AI Chatbot
- Attendance
- Results
- Assignments
- Notice Board
- Responsive UI

## Technology Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

## Deployment

Deploy using Render or Railway.
